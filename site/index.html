Playporter

Glissez-déposez un .aab, il part en Test interne sur Google Play. Le « Transporter » de Google Play, pour macOS.

Télécharger le .dmg ou le .zip

macOS 13+ Apple Silicon & Intel Signé & notarisé Apple

Comment ça marche

1

Connecte-toi

Un clic « Se connecter avec Google » — l'accès reste dans ton Trousseau, jamais ailleurs.

2

Dépose ton build

Glisse un ou plusieurs .aab n'importe où dans la fenêtre.

3

En ligne

Playporter détecte l'app et publie sur le canal Test interne. C'est tout.

Ce qu'il fait

Détection automatique

Le package et la version sont lus directement dans l'AAB — aucune config par app.

Connexion Google sécurisée

OAuth 2.0 (PKCE), jeton stocké dans le Trousseau macOS.

File d'attente & historique

Empilez plusieurs builds, suivez les envois, filtrez par application.

Zéro dépendance

Pas de Java, pas de fastlane. Une app native autonome.
